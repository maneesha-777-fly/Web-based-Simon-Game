# 🎮 Simon Says Game

A simple, interactive web-based **Simon Says memory game** built using HTML, CSS, and Vanilla JavaScript.

Test your short-term memory by repeating progressively longer sequences of flashing colors. Challenge yourself to reach higher levels as the game gets more difficult!

---

## ✨ Features

- **Interactive Gameplay**
- **Progressive Difficulty**
- **Score Tracker**

---

## 🛠️ Built With

- **HTML5:** Provides the game's structure and layout.
- **CSS3:** Adds styling, colorful game blocks, and visual transition effects.
- **JavaScript (ES6):** Handles DOM manipulation, event handling, and random sequence generation.

---

## 🚀 Getting Started

### Prerequisites

A modern web browser, such as Google Chrome, Microsoft Edge, or Firefox.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/maneesha-777-fly/simon-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd simon-game
   ```

3. Open `simongame.html` in your web browser.

---

## 🎯 How to Play

1. Press any key to start the game.
2. Watch the sequence of flashing colors carefully.
3. Click the colored boxes in the exact order shown.
4. Each correct round advances you to the next level.
5. Repeat the growing sequence without making a mistake!
